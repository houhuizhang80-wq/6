# 朕即江山 · 帝王权谋模拟器

一款帝王视角的权谋模拟游戏。你是皇帝，每天要批折子、见臣子、平衡朝局，
还要在几个皇子之间定下继承人。

双击 index.html 即可

## 玩法要点

- **日常政务**：批折子、召见独对、翻牌子、免税赈灾。
- **权术手段**：推恩令削弱藩王，或者静观其变；对贪墨帑银的臣子查还是不查。
- **突发事件**：边关急报、御史弹劾，每一次决断都会牵动朝中支持度。
- **继承人问题**：大皇子、二皇子、三皇子、四皇子各有关系网，
  立太子这一步往往会引爆矛盾。
- **情报线**：微服私访可以发现蛛丝马迹，为决断提供依据。
- **史官记录**：每个阶段结束会有「史官曰」的评价，你的作为会被记下来。

## 技术说明

- 纯前端单文件，HTML + 内联 CSS/JS，无构建步骤、无后端、无网络请求。
- 宣纸色系的水墨界面。
- 存档在浏览器本地。
